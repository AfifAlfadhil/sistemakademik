# SAKA — Sistem Asisten Kampus UNS

SAKA (*Sistem Asisten Kampus UNS*) adalah chatbot akademik berbasis **Retrieval-Augmented Generation (RAG)** yang dirancang untuk membantu mahasiswa S1 Universitas Sebelas Maret (UNS) memperoleh informasi akademik berdasarkan dokumen resmi universitas.  

Sistem ini memanfaatkan teknologi:
- **Large Language Model (LLM)**
- **Vector Database**
- **Sentence Embedding**
- **Prompt Engineering**

untuk menghasilkan jawaban yang lebih relevan, faktual, dan minim halusinasi.

---

## Cakupan Sistem

Sistem difokuskan untuk menjawab pertanyaan akademik terkait:
- Kalender akademik
- KRS & herregistrasi
- Cuti akademik
- UKT
- Skripsi / tugas akhir
- Peraturan akademik S1 UNS

Sumber informasi yang digunakan berasal dari dokumen resmi UNS yang tersedia secara publik.
